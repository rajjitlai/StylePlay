# StylePlay : Play in your own Style

**StylePlay** is a modern, interactive CSS playground that allows you to experiment with CSS properties in real-time. Designed with a premium dark-themed UI, it mimics a code editor environment to provide an immersive experience for developers and designers.

## ✨ Key Features

-   **Live CSS Editor**:
    -   Type CSS directly into a VS Code-style editor pane.
    -   Real-time updates: See your changes instantly on the preview elements.
    -   **Tab Indentation**: Supports standard code indentation.
-   **Smart Toolbar**:
    -   **Snippet Library**: Instantly load preset designs like *Neon Glow*, *Glassmorphism*, *Grid Layout*, and *Bounce Animation*.
    -   **Copy to Clipboard**: One-click export of your CSS code.
    -   **Reset**: Quickly revert to the default state.
-   **Responsive Testing**:
    -   **Device Toggles**: Switch the preview area between **Desktop**, **Tablet**, and **Mobile** views to test responsive designs.
    -   Automatic layout adjustments for mobile views.
-   **Premium Aesthetic**:
    -   Dark mode interface with glassmorphism headers.
    -   Clean typography using the Inter font family.

## 🚀 How to Use

1.  **Open** `index.html` in your browser.
2.  **Edit Styles**:
    -   Target classes like `.preview-box`, `.box-1`, etc. within the editor.
    -   Try changing colors, adding animations, or modifying layouts using Grid/Flexbox.
3.  **Use Snippets**: Select a style from the dropdown to see advanced CSS in action.
4.  **Test Responsiveness**: Click the Mobile icon to see how your grid behaves on small screens.

## 🎨 Classes to Target

-   `.preview-box`: The main container for all preview items.
-   `.box-1` to `.box-4`: Individual boxes for specific styling.
-   `body`: Style the entire page background.

## 🛠 Technologies

-   **Vanilla HTML5 & CSS3** (Variables, Grid, Flexbox)
-   **Vanilla JavaScript** (DOM Manipulation, Event Handling)
-   **Google Fonts** (Inter)
-   **FontAwesome** (Icons)
