PLAY IN YOUR OWN STYLE

You can use the following CSS Properties

  • background: color;

    You can use any color you want

  • background-image: url(https://imageurl/anypicture);

    You can use any image source url

  • background-position: center;

    center - to center the image, left - put at the left side, right and so on

  • background-size: cover;

    cover - to cover the section, contain - to contain the section, fit - to fit the section, etc.

  • width: any valuepx;
    height: any valuepx;
  • border-radius: 1 to 100% or 1 to 100px;

    will give the shape of the element

  • If you cannot change the property, try adding !impotant at the end of the property
    like background: red !impotant;
